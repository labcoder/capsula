# Threads

Click the dock, then **Threads…**, to find an earlier conversation. Choose a thread to read its
messages. The list loads more threads as you scroll, and Older messages loads earlier history.
Page Up and Page Down scroll the focused messages area.

Search matches a phrase in stored message text. Clear the search to return to recent threads.
A shortened message is labelled; reading the rest of that one message isn't supported yet.

Opening a thread makes the typing panel continue it. Double-tap left Ctrl + left Alt to type.
**New thread** opens the typing panel with no thread selected; its first message starts the new
conversation. Closing the threads panel doesn't erase anything or change that next-turn choice.

Esc stops moving work before clearing a drawing or dismissing the focused panel. Switching
away hides the panel. The panel reloads after reconnecting to the background process.

Thread deletion isn't available yet.
